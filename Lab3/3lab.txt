Требования к лабораторной работе № 3
3.1. Интерполяционные многочлены Лагранжа и Ньютона
Необходимо реализовать оба метода.
В результате работы программы необходимо вывести:
Исходные узлы интерполяции xᵢ и значения функции yᵢ.
Интерполяционный многочлен Лагранжа.
Таблицу разделённых разностей.
Интерполяционный многочлен Ньютона.
Значение многочлена Лагранжа в заданной точке x*.
Значение многочлена Ньютона в заданной точке x*.
Точное значение функции f(x*).
Абсолютную погрешность интерполяции.
Разность между результатами методов Лагранжа и Ньютона.
Также необходимо построить общий график, на котором должны быть показаны:
исходная функция;
многочлен Лагранжа;
многочлен Ньютона;
узлы интерполяции;
заданная точка x*.
3.2. Кубический сплайн
В результате работы программы необходимо вывести:
Исходные узлы и значения функции.
Коэффициенты aᵢ, bᵢ, cᵢ, dᵢ для каждого участка сплайна.
Интервал, на котором действует каждый полученный многочлен.
Значение сплайна в заданной точке x*.
Номер интервала, содержащего точку x*.
Проверку прохождения сплайна через исходные узлы.
Значения второй производной на концах интервала для проверки граничных условий.
Также необходимо построить график, на котором должны быть показаны:
исходные узлы;
все участки кубического сплайна;
заданная точка (x*, S(x*)).
3.3. Метод наименьших квадратов
Необходимо построить приближающие многочлены первой, второй и третьей степени.
В результате работы программы необходимо вывести:
Коэффициенты многочлена первой степени.
Коэффициенты многочлена второй степени.
Коэффициенты многочлена третьей степени.
Полученные многочлены P₁(x), P₂(x) и P₃(x) в явном виде.
Значения MSE1, MSE2 и MSE3, рассчитанные по всем исходным точкам.
Сравнение полученных ошибок и указание многочлена, который лучше приближает исходные данные.
Также необходимо построить общий график, на котором должны быть показаны:
исходные данные в виде отдельных точек;
многочлен первой степени;
многочлен второй степени;
многочлен третьей степени.
3.4. Численное дифференцирование
В результате работы программы необходимо вывести:
Исходную таблицу значений функции.
Точку, в которой выполняется вычисление.
Узлы таблицы, использованные при вычислении производных.
Значение первой производной.
Значение второй производной.
3.5. Численное интегрирование
Необходимо реализовать:
метод левых прямоугольников;
метод правых прямоугольников;
метод средних прямоугольников;
метод трапеций;
метод Симпсона;
уточнение результатов методом Рунге–Ромберга.
Результаты необходимо вывести в виде таблицы.
Для каждого метода необходимо указать:
Значение интеграла с шагом h₁.
Значение интеграла с шагом h₂.
Порядок точности метода p.
Уточнённое значение интеграла по методу Рунге–Ромберга.
Оценку погрешности результата, полученного с шагом h₂.
Если интеграл можно вычислить аналитически, дополнительно необходимо вывести:
Точное значение интеграла.
Абсолютную погрешность каждого численного метода.
Метод, давший наиболее точный результат.
График для этой части не требуется.
